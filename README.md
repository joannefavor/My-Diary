# My Diary — 주간 기록부

일주일 일정과 건강 상태를 한 화면에서 기록하고 추이로 보는 대시보드입니다.
의존성 없는 단일 HTML 파일이라 `index.html`을 브라우저로 열면 바로 씁니다.

## 기록하는 항목

| 구분 | 항목 |
|---|---|
| 일정 | 요일별 일정(시작·종료 시각) + 완료 체크 |
| 수치 | 수면(취침·기상 시각 → 시간 자동 계산), 혈압(수축기/이완기), 공복혈당, 체중 |
| 활동 | 운동(분·종목), 물 섭취(잔) |
| 습관 | 아침·점심·저녁 식사 + 끼니별 식단, 복약 |
| 주관 | 기분(5점), 전체평가(5점), 증상·메모 |

## 화면 구성

- **요약 타일** — 전체평가 주간 평균을 중심으로 10개 지표의 주간 요약. 각 지표에 정상·주의·부족 판정이 색과 기호, 글자로 함께 표시됩니다.
- **이번 주 일정** — 월~일 주간 캘린더. 요일이 열, 시간이 행인 격자에 일정이 블록으로
  놓입니다. 빈 칸을 누르면 아래 입력줄에 그 날짜와 시각이 채워지고, 내용을 적어 추가합니다.
  겹치는 일정은 나란히 갈라져 놓이고, 오늘 열에는 현재 시각 선이 그어집니다.
  종료 시각을 비우면 한 시간짜리로 봅니다. 시간을 적지 않은 일정은 맨 위 `시간 미정` 줄에 모입니다.
  `목록`으로 바꾸면 예전처럼 날짜별 목록으로 읽고 쓸 수 있습니다.
- **생활 습관** — 식사·복약을 칸 클릭으로 바로 체크. 물은 잔 수에 따라 색이 진해집니다.
  식단을 적어 둔 끼니는 칸에 마우스를 올리면 무엇을 먹었는지 보입니다.
- **건강 추이** — 지표별 차트와 종합 차트. 막대나 점에 올리면 그날 값과 판정이 나오고, `표로 보기`로 같은 데이터를 표로 읽을 수 있습니다.
- **하루 기록하기** — 날짜를 골라 전 항목을 입력하면 요약과 차트가 즉시 반영됩니다.
  식사는 끼니 버튼으로 체크하고, 옆 칸에 무엇을 먹었는지 적을 수 있습니다.
  식단을 적으면 그 끼니는 먹은 것으로 자동 체크됩니다.

## 데이터

입력한 기록은 브라우저 `localStorage`에만 저장됩니다. 서버로 전송되지 않고,
이 저장소에도 올라가지 않습니다. 기기를 옮기거나 백업할 때는 화면 아래
`JSON 내보내기`로 파일을 받고, 다른 기기에서 `가져오기`로 넣으면 됩니다.

### 적지 않은 값은 0이 아니라 빈칸입니다

요약은 항목별로 **그 항목을 실제로 적은 날만** 계산에 넣습니다. 운동을 적지 않은 주는
`0분 부족`이 아니라 `기록 없음`으로 남고, 식사 규칙성은 끼니를 하나라도 체크한 날만
분모로 씁니다. 복약도 비율 대신 복용한 날 수로 표시해서, 안 적은 날을 미복용으로
단정하지 않습니다.

운동을 `0분`으로 직접 넣으면 그것은 기록으로 쳐서 "그날은 운동하지 않았다"로 반영됩니다.

## 판정 기준

표시되는 판정은 일반 권고치를 기준으로 한 참고 표시이며, 진단이 아닙니다.

- 혈압 — 대한고혈압학회 진료지침 구간 (정상 / 주의혈압 130·85 / 1기 140·90 / 2기 160·100)
- 공복혈당 — 정상 70–99, 공복혈당장애 100–125, 당뇨 범위 126 이상 (mg/dL)
- 수면 — 성인 권장 7~9시간. 취침·기상 시각을 넣으면 잔 시간을 계산하며,
  자정을 넘긴 경우(예: 23:30 → 07:00)도 자동으로 처리합니다. 기록은 **그날 아침 일어난 잠**을 기준으로 합니다
- 운동 — WHO 주당 중강도 150분
- 물 — 하루 8잔(약 200ml) 기준

수치가 계속 범위를 벗어나면 의사와 상의하세요.

## 접근성과 표시

- 밝은 테마와 어두운 테마를 각각 맞춰 두었고, 시스템 설정과 뷰어의 테마 토글을 모두 따릅니다.
- 상태는 색만으로 구분하지 않고 기호와 글자를 함께 씁니다.
- 모든 차트는 `표로 보기`에 같은 값이 표로 들어 있습니다.
- 캘린더에서 좁아져 시각이 접힌 블록은 마우스를 올리면 전체 시각과 내용이 뜨고,
  `목록` 보기에는 같은 일정이 잘리지 않은 줄로 들어 있습니다.
- 좁은 화면에서 단일 열로 접히고, 표와 격자는 가로로 스크롤됩니다.
